# Pre-Live

Site oficial do Pre-Live: download para Windows, novidades e dúvidas. Compartilhe sua tela com os amigos em salas privadas; a voz continua no Discord.

- **Site:** https://gust4d3str0.github.io/pre-live/
- **Instaladores:** aba *Releases* deste repositório (cada versão traz o SHA-256).

Este repositório contém **apenas o site estático** (pasta `site/`) e os instaladores publicados em Releases. O código do aplicativo e do servidor de sinalização não está aqui.

O instalador não é assinado digitalmente: confira o SHA-256 antes de instalar.
