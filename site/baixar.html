Instalar

  1. Baixe e confira o arquivo

    Depois do download, abra o PowerShell na pasta do arquivo e rode o comando abaixo. O resultado precisa ser idêntico ao SHA-256 mostrado acima.

    Get-FileHash .\Pre-Live_*_x64-setup.exe -Algorithm SHA256

  2. Execute o instalador

    Se o Windows não tiver o WebView2 (já vem no Windows 11), o instalador o baixa sozinho, o que exige internet.

  3. Abra o Pre-Live

    Escolha Criar sala e mande o convite, ou Entrar em sala e cole o convite que recebeu. Quem só vai assistir também precisa do aplicativo instalado.

Aviso de segurança do Windows

O instalador não é assinado digitalmente (certificado de assinatura de código é pago). Por isso o Windows pode mostrar “O Windows protegeu o computador” (SmartScreen).

  • Só continue se o SHA-256 conferir e se você baixou esta página oficial.
  • Se o SHA-256 for diferente, não instale.
  • No aviso, Mais informações → Executar assim mesmo aparece apenas para este arquivo.
  • Não desative o SmartScreen nem o antivírus.
  • Se o Controle Inteligente de Aplicativos (Smart App Control) estiver ligado, ele pode bloquear o instalador sem dar a opção de continuar. Nesse caso o Pre-Live não instala neste PC por enquanto. Não desligue o recurso só para isso: ele não volta a ligar sem reinstalar o Windows.

Requisitos

  • Windows 10 ou 11, 64 bits.
  • Microsoft Edge WebView2 Runtime, instalado automaticamente quando falta.
  • Internet estável. Quem transmite precisa de upload: veja a estimativa no próprio aplicativo antes de começar, principalmente em salas grandes.
  • CPU: transmitir em 1080p usa bastante o processador. Se travar, baixe para 720p nas configurações.

Desinstalar

Configurações do Windows → Aplicativos → Aplicativos instalados → Pre-Live → Desinstalar.
